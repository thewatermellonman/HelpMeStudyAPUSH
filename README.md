# HelpMeStudyAPUSH
A simple notes app to help you study APUSH! It's completely offline (cause school internet sucks)

This project stayed pretty basic, it was mostly me trying to figure out IndexedDB, which was wayyyy more complicated than I thought

## Features

- Notes grouped by APUSH unit
- Create, save, delete, and edit notes
- Data stored locally with IndexedDB

## How do I use it?

1. Click a unit card
2. Click "+ Upload Notes"
3. Edit the title and content, and then save!

## Files
index.html -- Page structure
style.css -- Style
app.js -- UI logic
db.js -- everything IndexedDB

## Notes
- All of your notes stay in this browser only. If you clear site data, you lose your notes.
- No internet is required after the first time you load it
